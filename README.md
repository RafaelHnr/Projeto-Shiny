Projeto acadêmico desenvolvido em grupo utilizando R e Shiny.

## Como executar

1. Abra o arquivo `Projeto-Shiny.Rproj` no RStudio.
2. Instale os pacotes necessários.
3. Execute o arquivo `app.R` utilizando o botão Run App.

## Estrutura do projeto

- `app.R`: arquivo principal da aplicação.
- `R/`: scripts e funções auxiliares.
- `data/`: bases de dados.
- `www/`: arquivos visuais, CSS e imagens.
